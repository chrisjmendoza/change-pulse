# Extension artwork

This folder contains the icon assets for Change Pulse.

- `change-pulse-icon.png` — generated 1254x1254 PNG, selected in `package.json` for Marketplace packaging. A document with code lines and an amber pulse represents a recent edit.
- `icon.png` and `icon.svg` — original artwork, retained for reference; the SVG is not the source for the new PNG.

## Generation

Created with the built-in image generation tool. Prompt recorded in `icon-prompt.txt`.

## Suggested marketplace usage

- Use the PNG as the packaged extension icon.
- Keep the icon square and centered with clear contrast.
- Use a simple background and bold pulse motif so it remains legible at small sizes.
