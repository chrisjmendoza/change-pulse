# Change Pulse

## Concept
Change Pulse is a lightweight VS Code extension to help developers visually see when a file has been edited recently.

## Goals
- Highlight recently modified content in editors.
- Make modified files obvious in the Explorer.
- Show recent +/− line counters in Source Control.
- Offer a simple extension that is useful in active development workflows.

## Current status
- Base extension scaffold is complete.
- Editor flash and Explorer badge are implemented.
- SCM recent-change tracking is in place.
- Standard project docs are added.
